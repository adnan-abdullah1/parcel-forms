PARCEL FORMS

Open index.html in a modern web browser. The menu at the top switches between
Parcel declaration and Invoice. Fill in the shipment details, then use the
green download button. In the browser's print/share screen, choose Save as PDF.

The page is self contained and works without a server. The form starts empty,
apart from the consignee details requested for the declaration. It starts with
one item row; use Add another item to add more. Required information is checked
before the PDF is opened. Form entries are saved in the browser on that device
so they are still there when the page is reopened.

The app shell is cached for offline use after the page has loaded once while
online. Android users can install it from the browser menu. On iPhone, use
Share > Add to Home Screen. Shipment details remain in local browser storage.
Use Reset saved details before handing the device to someone else.

To make it available as a web link on the friend's phone, publish index.html
and this folder on a static web host. The current version keeps information on
the device; it does not send or sync customer data to a server.
